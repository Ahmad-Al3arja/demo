# Mwasalati - Ride Simulation

Mwasalati is a premium interactive ride-hailing simulation demonstrating synchronized real-time state management between a passenger and captain app.
Built for the Palestinian West Bank region, it showcases automated dispatching, high-fidelity Leaflet map navigation, and realistic vehicle telemetry.
The application features a sleek obsidian monochrome aesthetic, responsive split-screen device mockups, and localized Palestinian license plates.
With a fully automated end-to-end trip lifecycle and repeat flow controls, it serves as an immersive presentation and testing showcase.
Powered by React and Vite, the platform delivers fluid 60 FPS animations and seamless live route tracking without manual intervention.
